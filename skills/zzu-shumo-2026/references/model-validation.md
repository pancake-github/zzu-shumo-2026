# 方法选择、数学分析与验证

先明确要解释、预测或决定什么，再结合独立样本、结构、约束和计算预算选择方法。历史论文的方法名称用于检索；实际采用前核对定义、求解和检验。具体资料见 [方法目录](method-catalog.md)。本页用于建模与验证，不要求文字修订任务重做计算。

## 按任务选择证据

| 任务 | 方法选择要点 | 有效核查方向 |
|---|---|---|
| 描述统计与时空变化 | 区分总量、平均量、变化率和分布 | 单位、范围、覆盖、分组及聚合口径；不强加预测指标 |
| 统计关联与推断 | 变量类型、重复测量、混杂和多重比较 | 效应量、不确定性及假设条件；小 p 值与大效应或因果关系分别判断 |
| 回归预测 | 预测时点、非线性、外生信息和分布变化 | 符合用途的留出或回测、简单基准、误差和残差；训练拟合不等于外推能力 |
| 分类识别 | 标签定义、错误代价、分组独立性和类别比例 | 各类召回、精确率及合适汇总；阈值在训练或验证环节确定 |
| 聚类分区 | 距离、缩放、簇形状和分组用途 | 内部指标、初始化或样本稳定性、外部含义；可视化分离不单独证明聚类有效 |
| 综合评价 | 指标方向、尺度、权重依据和评价对象 | 权重、处理方式及指标变动对排序的影响；方法内部一致性与现实有效性分别检验 |
| 优化决策 | 目标、可行域、离散与连续结构 | 约束满足、基线、小规模对照及适用的界或间隙；启发式最好解保留其求解性质 |
| 机理与仿真 | 守恒、边界初值、参数来源和可识别性 | 量纲、极限、数值收敛、观测对照及参数敏感性；仿真自洽与现实验证分别说明 |
| 信号处理 | 采样率、窗口、重叠、滤波和边界 | 已知信号对照、噪声与参数敏感性、记录级划分 |
| 图论与数值计算 | 网络方向、权重、连通及矩阵结构 | 小规模正确性、边界、实际运行成本；理论复杂度与实测加速分开报告 |

选择与当前判断有关的检验，不把表中方向全部执行。没有标签或独立数据时，采用可实施的合理性或稳定性检查，明确所得证据的范围。

## 模型与验证的对应关系

模型定义应能追溯至变量、单位、假设、目标和约束。说明参数来自何处、如何估计，以及停止条件或求解精度如何确定；论文保留理解结果所需的部分，程序重试和末位误差不必进入正文。首次方法介绍及跨问符号统一见 [论文写作](paper-writing.md)。

同一主线可包含主模型、基线和解释性对照，各自承担明确职责。采用多模型不自动意味着集成；比较时统一数据划分、目标口径和评估信息边界，按模型职责说明输入差异。简单基线允许合理简化，但不能故意设置不利条件或使用测试集均值。只有比较实际完成且指标支持时，才说明性能改进。

参数、阈值和搜索范围有数据或任务依据。若最优结果落在搜索边界，检查边界是否由现实条件决定；否则先评估范围是否足以支持结论。聚类编号、树分裂或内部评分本身不提供现实风险等级定义。

数值求解优先检查原始约束、目标复算、单位还原和边界情形。需要最优性声明时，使用适合该问题的界、间隙、对偶或可比精确结果。无法收敛、输入来源冲突或可靠界相互矛盾时，保存诊断并停止依赖结果；不通过放宽精度或删去失败条件美化结论。

## 参数方向异常或验证不佳时

| 发现 | 默认检查 | 结论边界 |
|---|---|---|
| 系数符号与直觉相反 | 核对目标方向、单位、变换、公式实现、样本构成、共线性及时间覆盖 | 先保留原结果；不能仅为了符合预期换符号、删低分样本或强加正约束 |
| 时间、规模或其他因素难以区分 | 检查设计矩阵秩、变量相关性、分组覆盖和参数稳定性 | 识别较弱时降低归因强度，不直接计算稳定的因果占比 |
| 基线表现更好 | 确认训练成员、权重、输入和指标一致，再检查误差集中位置 | 如实报告对照，不为得到优势临时增添大量候选模型 |
| 参数边界或多个近优解 | 检查约束依据、近优解和关键输出对完整参数向量的变化 | 参数不唯一时区分代表解与可识别结果，不拼接各参数独立极值得到虚构方案 |
| 局部映射被用于范围外 | 核查拟合对象、协议及单变量和联合覆盖，分别报告范围内检验与范围外换算 | 局部误差不是外推误差保证；换算超过有效取值范围时标明，不能静默裁剪 |
| 新研究对象可能更符合题意 | 重新明确估计对象及假设，例如均值关系、可达到的边界或资源上限 | 此类变化属于研究设计调整；有数学依据的单调约束可以采用，但约束本身不是实证发现 |

上述检查用于定位原因，并不要求每次都增加一套敏感性矩阵。若现有资料已经能说明问题，直接形成结论；改变研究目标或数学机制且授权范围不明确时，先呈现具体依据再集中确认。

## 不确定性与外推

测量或抽样误差、算法运行变动、模型或处理假设的敏感性分别解释。不同情景端点、不同留出成员参数产生的范围属于相应来源的变化范围，不自动称为置信区间；重采样保持数据依赖结构。误差来源不能识别时，说明缺少的证据，不生成装饰性误差条。

跨来源应用先确认单位、测量定义、时间口径及样本可比性。仅做边际范围检查不足以证明变量组合获得支持；组合条件、训练阶段和数据来源发生改变时，在结果解释中说明。预测时保留当时可用信息集，后期统一评测的回溯与实时预测分别表述。

未来情景是明确的延续假设，数量服从题目与核心判断，不预设必须穷尽增长、停滞或所有参数组合。保留有实际用途的回溯和敏感性；历史检验的时间跨度如实报告，不能直接换算成更长预测期的误差保证。

跨问误差只沿实际依赖关系传播。若后续模型直接使用另一组观测，其不确定性单独评价，不机械叠加未被使用的中间映射误差。

回归系数、相关系数、特征解释和模型内贡献分别对应条件关系、统计关联或预测分解。因果判断另需设计、识别假设和领域依据；未解释的观测差异不能直接归给某一种机制。

## 报告与实现依据

检验说明目的、数据或扰动、指标、结果及其对结论的影响。重要不利发现保留在相应位置；将具体条件集中说清楚，避免每段重复抽象限制。只有已有比较支持时，使用“更准确”“更稳定”或“计算更快”等判断。

软件实现涉及版本差异时核对当前官方文档。可用入口包括 [scikit-learn 数据泄漏](https://scikit-learn.org/stable/common_pitfalls.html)、[交叉验证](https://scikit-learn.org/stable/modules/cross_validation.html) 和 [statsmodels 预测与回测](https://www.statsmodels.org/stable/examples/notebooks/generated/statespace_forecasting.html)。教学帮助页用于操作检索，疑点回到方法定义及原始来源。
