# 比赛论文写作

在撰写、精简或审阅数学建模论文时按需读取。优先采用当前题目、正式规则、用户要求和已有稿件；历史论文与教学资料用于理解写作方式，不能替代本次要求。相关证据见 [来源说明](evidence.md)。

## 题意主线与分析取舍

围绕题目形成清楚、可信、能够解释的求解路线。遇到以下情境，直接采用对应处理；只有材料不足以确定研究含义或修改范围时，才集中询问。

| 情境 | 默认处理 | 保留的边界 |
|---|---|---|
| 题目允许多种方法、函数或情景 | 完整阅读题干与附录，区分必答任务、必要验证和可选扩展；选择主方案及有明确用途的对照 | 允许选择主方案不取消其他位置要求的比较；也不机械限制为每问一种方法 |
| 已有结果很多，正文缺乏主线 | 按“回答哪项要求、支持哪项判断”筛选和组织；复用已有计算 | 改写论文不自动触发重新拟合、优化或全组合试验 |
| 图表和文字重复报数 | 图展示分布和变化，表保留需准确查阅的数值，文字解释主要发现；相关图用简短逻辑串联 | 保留独有证据、指定验证和会改变结论的不稳定结果，不能为缩短篇幅删去反例 |
| 公式多、辅助推导打断阅读 | 保留模型定义、首次方法介绍所需关系、关键推导与可解条件；简单统计量和辅助定义可改为行内说明 | 不因精简删除理解核心结论所必需的公式；不按固定公式数或减页比例取舍 |
| 删除重复内容后考虑附录 | 冗余内容直接退出正文，已有计算记录保留事实 | 只有正式要求或实质复现需要时才安排附录，不用附录收纳所有删去的内容 |

取舍后同步本次涉及的正文来源、生成入口和引用，防止重建恢复旧内容。科学计算记录保持原有范围，不能因展示缩减而改写实际完成的工作。

## 逐小问研究与写作流程

用“问题—方法—模型—结果”组织论证，章节名称和层级服从模板与研究关系，不要求每问复制同一目录。共享数据处理和通用方法在首次使用处说明，后文解释新增部分即可。

### 问题理解与研究路线

背景回答“为什么值得研究”；问题重述回答“对象是什么、已有条件是什么、需要完成什么”。重述用自己的语言提炼题意，已知事实直接陈述，待完成工作写为“需要建立”“还需分析”等，避免提前写成已经完成的方法或结果。多小问分别回应，保持其约束和目标。

研究路线说明方法之间的输入输出关系。复杂联系适合画路线图，简单任务用一段文字即可，不要求每问配图。图中步骤应与实际研究一致，不能把计划中的分析当作已经完成的证据。

### 数据与模型建立

数据部分重点交代独立样本单位、来源、影响结论的处理及最终用途。重复、缺失、时间、单位或连接问题按实际情况说明；表格与流程图择其清楚者，不以处理步骤数和运行工作量充当贡献。重复来源、模拟条件和重采样轮数与独立样本量分别计数。

假设紧扣模型实际需要，说明简化对象、合理依据与适用范围；可按简化性、约束性和机制性组织，但不为凑类别增加假设。题给约束、符号定义和推导结果放在各自位置。预测情景属于自选条件，应与题目要求区分。

模型部分定义变量、单位、目标、约束及参数来源，再说明方法怎样用于当前问题。模型评价围绕已有比较与验证展开，不能把常见算法优点直接写成本文实验结论。

## 方法与缩写首次使用

遇到具体方法或数据缩写首次正式出现，先用简短、直接的语言说明“是什么”，再连接当前用途；后文已经解释过的内容直接引用。仅在摘要或路线图中出现名称，不算完成正式介绍。

- 具体方法说明输入、输出或基本机制；读者理解后续模型需要时，补充基础关系及符号。例如，岭回归是在残差平方和中加入系数平方惩罚的回归估计方法，再说明当前估计对象与惩罚项。
- 缩写写明全称、含义及与数据的关系。来自附件的分类得分，应说明它是哪个模型或规则产生的字段，避免被误解为本文新方法。
- 研究对象、分析任务和数学量分别给必要定义，不都包装成方法教程。本文构造的函数形式直接说明依据，不能借方法名称将其写成已经验证的定律。
- 通用原理介绍到能理解当前模型为止，不固定“定义、公式、优点、用途”的段数；后续章节只解释新增变量、约束或变体。

求解说明围绕估计目标、样本划分、选择依据和必要数值策略展开。程序重试、报错分支、循环次数等通常保留在代码中；某项设置实际影响结论时，解释其作用及检查结果。

公式前后组成完整句意：先说明定义或计算目的，公式后解释统计对象和判断依据。不要把“依据”与其宾语、或“通过”与其动作拆在陈列公式两侧。

## 语言审查：去套话并保留科学含义

用户只要一句可复制的改写时，直接给出句子；不启动整篇审计、文档构建或阶段验收。要求只检查时仅提供意见；已授权修改时直接在指定范围内改写。用户指定逐句五栏等格式时按其格式输出，普通润色不默认生成大型检查表。

| 发现的问题 | 默认修订方式 |
|---|---|
| 句式杂糅、主谓宾搭配不自然 | 先找主干，保留一种表达结构；优先改动连接词、语序与搭配 |
| 定语堆叠、一句混入定义原理和用途 | 按“是什么—如何使用”整理，必要时拆句，不把简单句改复杂 |
| 语义重复、空转连接词 | 删除无新增信息的成分，明确依据、手段、因果或并列关系 |
| 生硬缩写、术语机械拼接 | 采用准确通行名称，并用直观中文说明对象；不为高级感大量换同义词 |
| “已核验”“未擅自修改”等过程性反馈 | 正文直接说明实际处理、结果及用途，交付状态留在简短工作说明 |
| 反复“仅用于……不能……”或泛泛提醒 | 集中说明估计对象、证据范围和适用条件；避免每段重复防御性说明 |
| “显著改善”“稳定可靠”等空泛判断 | 有证据则给比较对象、指标和条件；缺少相应检验则降低或删去判断 |

否定词、条件句和谨慎结论本身不是错误。保留影响结果含义的失败情形、定义域、外推条件和数据限制，不把“正面表达”理解成只报好结果。例如，“不能作为置信区间”可在含义足够清楚时改为“该范围表示不同参数设置造成的预测变动”；若读者仍易混淆，保留必要区分。

每次改写保持对象、数量、比较方向、因果关系、单位和结论强度。含义有歧义时先查相邻公式与结果；仍无法确定则保留该处并一次性指出具体疑问，其余确定的修改继续完成。不要额外增加方法优点或实验效果。

## 术语与计数口径

沿用题目核心术语，专业名称、原始字段和引用题名按真实含义保留。区分研究对象、题给任务、自选方法和计算发现；不要因题干未出现某个合法方法名称就否定其使用，也不要将内部简称当作读者已经理解的概念。

数量对应其统计单位：模型、样本、记录出现次数、组合项、模拟条件、重采样轮次分别说明。只有明确分类及证据支持，才将计算组合称为现象类别。论文符号与代码字段可建立简短映射，无需为普通措辞改动更改科学接口。

## 数学符号与跨小问一致性

变量通常用普通斜体，向量或矩阵可用粗斜体；单位、运算符和说明性下标用正体，变量索引用斜体。遵循当前模板和学科惯例，标准集合符号及具有数学含义的字体可以保留，不能一律删除花体或黑板粗体。

合并章节时核对完整符号的含义、范围或维度、单位。共享量统一记法，不同对象避免重名；局部哑索引可复用但应明确范围。集中符号表收录核心量，局部辅助符号在首次使用处解释，不追求收录所有字符。

修改符号应按含义同步正文、公式、表头和图中文字，避免单字母全局替换。Word同时检查源记法、Office Math样式和实际字形，防止变量意外变为花体、下划线或错误上下标；不能只以源码搜索判断显示正确。

## 结果段落、模型评价与本问小结

结果段先给比较口径，再用图表展示主要发现，并解释其与目标或约束的关系。核心数值可追溯到已有结果，训练拟合、独立检验、条件计算和未来预测各有明确含义。

模型检验提供证据，本问小结提炼答案，避免两处重复完整过程。小结按照题目及子问说明“采用什么、得到什么、回答什么”，适量保留代表数字和必要条件；不机械重复“本文认为”，也不把适用条件堆成结尾。

全篇评价围绕实际证据：优点说明具体设计和用途；缺点直接说明哪种简化或数据不足造成什么影响；展望概括类似场景应用和进一步研究方向。改进应对应局限，但无需在收尾罗列字段和算法步骤。创新可突出本文针对问题的组合或推导设计，使用“首次”“原创”等判断前须有依据。

## 摘要与题名

主要结果确定后再形成摘要；已有摘要修改按用户指定范围处理。摘要能独立说明问题、核心方法、结果和含义，逐问覆盖，含多个小问时分别概括其贡献。可采用概述加分问段落，不固定段数、字数、页数或关键词数量，正式要求优先。

选代表数字时保留比较基准和关键条件，避免把训练精度写成检验表现、条件优化写成实际收益、情景预测写成保证。重要局限只用必要短语说明，细节留在正文。摘要不依赖章节号或图表号才能理解。

题名和关键词突出实际研究对象与主要任务，避免堆砌未使用的方法。需要强调重点时选择核心设计、关键结果或判断局部加粗，不整段加粗；加粗不应割裂结果与成立条件。结论与摘要呼应，表达各有侧重，不直接复制整段。

## 图、表与公式

图表按论证作用选用，不设数量配额。正文说明比较对象和主要关系，图展示分布或趋势，表提供准确值；相关图可成组解释。误差条明确代表标准差、标准误差、置信区间或参数变动，不能因视觉需要补造误差。

新图可采用 [绘图规范](figures.md) 的推荐设置；修改现有图则保留数据、坐标、画幅与整体风格，在最终文档显示尺寸下调整文字、重叠和留白。字体、分辨率与题注形式服从模板和用户要求。表格可采用 [三线表](three-line-tables.md)，精度按实际辨识需要设置；缩短数字只改显示，不改原始计算精度。

公式优先可编辑形式，保留核心模型及配套推导。图表公式的编号和引用遵循当前工程；跨章合并时同时调整对象、题注、正文引用和目录，不单改可见编号。

## 中间产物与DOCX交付

采用用户已有正文来源和工作流。完整研究可用Notebook、Markdown与结果表积累证据，Word是推荐交付形式，LaTeX或其他格式按用户要求使用。方法稿、章节稿、单句修订和完整稿分别按当前任务交付，不把完整小问作为所有文档编辑的前置条件。

用户手工修改后的稿件若为当前依据，先核对它与生成来源的差异，再定点修改并同步授权范围内的来源，防止重建覆盖有效手工内容。实际排版与分页检查见 [排版分支](word-latex.md)，核验深度见 [交付核查](review.md)。不为小修改新增庞大状态文件或重复报告。

外部事实与方法引用先核对原文、正式出版信息及支持位置；不给未阅读来源补造页码或结论。附录和文献数量服从当前需求，不把某次项目比例固化为规则。需要比较历史组织方式时，按需读 [写作风格交叉分析](<evidence/写作风格交叉分析.md>)；其中样本仅代表已抽读范围。
