# 数据处理与计算组织

用于读取、连接、清洗和形成模型输入。按当前数据问题选择处理，不把本页当作每份数据都要执行的完整清单。具体方法资料见 [方法目录](method-catalog.md)；历史材料的来源见 [证据说明](evidence.md)。

## 先核查影响结论的信息

明确一行代表什么，以及哪些行来自同一对象：独立个体、设备、时间窗、重复测量或原记录的派生版本。建立实际使用字段的含义、单位、缺失编码、标识键、时间精度、来源及用途；小表可直接在现有说明中记录，无需另造文件。

重点检查会改变比较或估计的字段。类别标签不表示数值大小；累计投入、去重数量、单次用量和新增用量应分别解释；上界、下界、近似值与测量值保留其性质。仅有上界时可以讨论该预算内的可达性，不能将其写成已知实际消耗；缺失的追加投入不能默认补零。

原始数据保持只读。文件来源、版本、处理方法和必要的可复算关系随现有计算记录保存；跨阶段复用或覆盖风险较高时，增加输入指纹核对。中间文件按实际用途保存，不为形式复制全部数据。

## 多来源数据按用途形成样本

| 触发情境 | 默认动作 | 适用边界 |
|---|---|---|
| 名称相似或同源重复 | 用身份、版本及关键条件核对，区分同一记录重复出现和合法重复观测 | 名称匹配仅作为检索线索；重复评测不自动增加独立样本量 |
| 多表连接 | 先检查连接键与一对一、一对多关系，再核对行数、未匹配和重复增殖 | 连接后的记录数变化应能由关系解释；不能把笛卡尔增殖当作新增观测 |
| 日期含义或精度不同 | 区分发生、发布、采集和评测时间，按研究用途确定时间轴，保留原日期精度 | 后期统一评测形成的历史序列属于回溯比较；预测信息集另按当时可用信息界定 |
| 指标或评测协议不同 | 优先采用同定义、同单位、同协议记录，必要时分别建组或建立有证据的换算 | 无共同标尺时保留差异，不能仅因字段同名直接拼接 |
| 样本训练阶段或处理方式不同 | 保留类型和阶段；能关联母记录时建立关系，说明追加与继承投入 | 分层描述可纳入更多对象，资源归因则需相应投入信息，不能混用分母 |
| 核心元数据不完整 | 按用途决定保留范围，例如用于历史描述、局部比较或资源估计 | “尚未核实”不等于“不符合”；不因一项用途缺字段就从所有分析中删除 |
| 真实观测、估算和半合成数据混合 | 保留来源标记，分别说明能支持的判断 | 同源估算不作为独立实测验证，半合成拟合结果不能替代真实训练效果 |

筛选依据来自题目和研究对象，不根据得分、系数方向或预测好坏制定。开放性、许可、模型类型等要求须结合题目原句理解；若允许选择筛选口径，说明所选依据，不将所有列举项自动设为必须同时满足的门槛。各用途样本允许重叠，其数量分别报告。

## 先定验证边界，再拟合处理

预测任务先确定预测时点、目标、当时可用信息和独立划分单位。时间预测用向后检验或滚动回测；同一原记录、人、设备或模型家族产生的样本按相应组划分。空间外推考虑地理阻隔。验证方式服务实际应用场景，不为了得到更高分数改变划分。

折数与类别覆盖依据独立组数确定。样本少时使用可实施的分组或时间验证并说明范围；增加窗口或过采样不能增加独立对象数量。填补、标准化、降维、特征选择及重采样在训练集或每个训练组内拟合，再用于相应验证部分。

模型与参数选择在最终评估边界之内完成。使用交叉验证同时选模和估计表现时，考虑内外层设计或独立留出；反复根据同一测试分数选择方案会影响其作为最终泛化证据的含义。描述性统计可使用全部已知数据，但不沿用其事后信息建立预测输入。

## 按诊断决定变换

| 问题 | 默认检查与处理 |
|---|---|
| 缺失 | 核对编码、模式与成因，再选择保留、删除或填补；按受影响字段与样本说明变化，时间插值只用预测时点可获得的信息 |
| 异常或极值 | 核对单位、仪器、录入及真实极端事件，区分标记和删除；若处理影响结论，比较保留与处理的结果，箱线图阈值仅作筛查 |
| 数值尺度 | 按单位与算法需要决定缩放；物理换算与统计标准化分别解释，树模型不因惯例强制标准化 |
| 类别不平衡 | 根据类别数量、错误代价和独立对象数选择权重、阈值或训练内重采样，报告有实际含义的分组指标 |
| 时空对齐 | 核对坐标、时区、频率及累计量，按用途选择聚合、插值或多尺度处理，并说明新增误差 |
| 特征工程 | 明确输入、公式、单位及预测时可用性，重点检查目标派生字段、事后信息和跨组聚合 |

涉及删行、合并、筛选或填补时，保存足够说明记录去向的数量和原因；若数目不一致，先定位差异，再推进依赖分析。普通显示格式修改无需重新审计全部附件。

## 计算与图形交付

已有环境、语言与交付形式优先。未指定时可用 Notebook 组织数据分析：Markdown 交代目的、输入和判读，代码在关键处理处加简洁中文注释；用户需要逐行讲解时再增加注释密度。先读取真实表头和数据结构，不生成依赖未知字段的占位代码。

对实际计算保留环境、输入版本、参数及适用的随机种子。固定种子便于复现，不能替代必要的样本或初始化稳定性检查。提交可执行计算时在干净内核顺序运行并核对导出结果；若只改文字，不重复训练。用户要求自己逐单元运行时，给当前步骤并等其实际输出后推进依赖计算。

科研图按 [绘图规范](figures.md) 处理。新图可复用 `scripts/figure_style.py` 和 `examples/figure_gallery.ipynb`；已有图优先保留数据、坐标和风格，只做授权调整。误差条来自明确的不确定性定义，不根据数组形状推断。默认可采用 SciencePlots 与 600 dpi 位图，用户模板、已有风格或指定分辨率优先；按实际输出核对字号、裁切和图中数值。教学示例仅用于演示流程。
